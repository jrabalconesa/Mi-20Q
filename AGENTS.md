# AGENTS.md — Proyecto 20Q

## Objetivo
Desarrollar un juego web de veinte preguntas estable, accesible y fácil de ampliar.

## Reglas
- React + TypeScript estricto.
- Mantener la lógica del juego fuera de los componentes.
- Evitar `any`.
- Mantener funciones puras en `src/engine`.
- Añadir o actualizar pruebas cuando cambie el comportamiento.
- No añadir dependencias sin justificarlo.
- La interfaz visible estará en español.
- Diseño accesible y responsive desde 360 px.
- Antes de cerrar una tarea ejecutar `npm run test` y `npm run build`.

## Entrega
Informar de archivos modificados, decisiones tomadas, pruebas ejecutadas y limitaciones pendientes.
